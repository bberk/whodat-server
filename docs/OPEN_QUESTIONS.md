# Open Questions and Deviations

Agents append an entry here (instead of guessing) when a spec document is wrong, missing, or
ambiguous, or when implementation deviates from a document. Each entry records:
- **Found**: what was found and why it is ambiguous or missing.
- **Options**: viable paths considered.
- **Recommendation**: the recommended approach.
- **In the meantime**: the conservative interpretation or temporary action taken while awaiting confirmation.

Historical resolved questions have been archived in [`docs/DECISIONS.md`](DECISIONS.md).
